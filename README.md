# برد پروژهٔ سوسیسا (Glitch Lab)

برد مستقل و نصب‌شدنی (PWA) بدون Claude و بدون سرویس دیگر. خود برد روی **GitHub Pages** است و دادهٔ مشترک روی شاخهٔ **`board-data`** همین مخزن. هر تغییر یک commit است؛ دستگاه‌ها تا حدود ۱۵ ثانیه بعد آن را می‌بینند.

**آدرس:** https://theglitchlabstudio-source.github.io/Susisa-projectboard/

## نصب (روی هر دستگاه)
- **اندروید (Chrome):** منو ⋮ ← Install app
- **آیفون (Safari):** Share ← Add to Home Screen
- **لپ‌تاپ (Chrome/Edge):** آیکون نصب کنار نوار آدرس

## وصل‌کردن برای ویرایش (یک‌بار روی هر دستگاه)
1. امیرحسین باید در مخزن Collaborator با دسترسی Write باشد (Settings ← Collaborators).
2. https://github.com/settings/personal-access-tokens/new ← نام «susisa-board»، Repository access: فقط `Susisa-projectboard`، Permissions ← Contents: **Read and write**. (اگر مخزن مال حساب دیگری است، توکن Classic با دسترسی `repo` بسازید.)
3. برد ← ⚙ تنظیمات ← «اتصال GitHub» ← توکن را Paste ← «ذخیره و اتصال». نشان بالای صفحه می‌شود «آنلاین · همگام».
4. در «پروفایل من» نام خود را انتخاب کنید (با ورود GitHub، دفعهٔ بعد خودکار انتخاب می‌شود).

بدون توکن، برد فقط‌خواندنی است. توکن فقط در همان مرورگر ذخیره می‌شود و داخل مخزن نیست.

## آپدیت
هر commit روی `main` خودکار روی Pages می‌آید؛ برد با باز شدن یا بازگشت به برنامه نسخهٔ جدید را می‌گیرد و بنر «نسخهٔ جدید» نشان می‌دهد. تغییر داده (تسک و…) نیاز به آپدیت ندارد.

## Claude در برد
پروفایل «Claude» (`CL`) دارد و می‌تواند تسک بخواند، بسازد، ویرایش و کامنت کند. ابزار `tools/board.py` و راهنمای `CLAUDE.md`.

## حریم خصوصی
مخزن Public است، پس دادهٔ شاخهٔ `board-data` برای هر کسی با لینک قابل خواندن است. اگر نمی‌خواهید: یک مخزن **Private** بسازید، شاخهٔ `board-data` را آنجا بگذارید و در برد ← تنظیمات ← «مخزن و شاخهٔ داده» مالک/مخزن را به آن تغییر دهید (برد می‌تواند در همین مخزن Public بماند؛ توکن باید به مخزن Private هم دسترسی داشته باشد).

## نکات
- فایل ضمیمه تا ۲۰ مگابایت داخل `files/` شاخهٔ داده؛ بزرگ‌تر را لینک کنید.
- تغییرهای آفلاین در دستگاه می‌ماند و بعد از اتصال ثبت می‌شود.
- ویرایش هم‌زمان دو نفر روی یک تسک، فیلد به فیلد ادغام می‌شود.
