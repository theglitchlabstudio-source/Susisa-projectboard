# پیام آماده برای چت دستیار: «همه‌چی رو تحویل بده»

این متن رو تو هر چت قبلی دستیار پروژه (که توش کار سوسیسا انجام شده) بفرست:

```
همهٔ چیزهایی که تو این چت دربارهٔ سوسیسا ساخته یا دریافت شده رو تحویل بده:
1. برای هر تسک یه «بلوک تحویل» طبق agent/copilot/HANDOFF.md (عنوان تسک، وضعیت، خلاصه، تصمیم‌ها، کنترل کیفیت، برای بانک دانش).
2. متن‌ها (سناریو، کپشن، بریف، تقویم) رو به‌صورت فایل md روی همون تسک با `board.py attach` بذار؛ اگه شِل نداری، متن کامل هر فایل رو تو یه بلوک کد جدا بده تا کپی کنم.
3. فایل‌های رسانه‌ای (ویدیو، عکس) رو نام ببر و بگو کدوم تسک؛ خودم آپلود می‌کنم.
4. تصمیم‌ها و تاریخ‌های تازه رو زیر «رویدادهای تازه» در kb/BANK.md اضافه کن.
بدون مبلغ، بدون رمز.
```
اگه دستیار شِل نداشت، خروجیش رو تو گفتگوی برد (یا یه کامنت روی تسک) پیست کن؛ ایجنت اجرای بعد همه رو روی برد می‌بره.
