# قالب بلوک تحویل
دستیار در پایان این را می‌نویسد؛ کاربر می‌خواند و تأیید می‌کند؛ بعد با پیشوند `@Claude` روی همان تسک کامنت می‌شود.

```
@Claude تحویل تسک <شناسه> — <نام کاربر>
وضعیت پیشنهادی: done | review | doing | paused (دلیل)
خلاصه: <۲ تا ۴ خط چه شد>
تصمیم‌ها: <تصمیم‌های گرفته‌شده با مبنا>
فایل‌ها: <نام فایل ← محل: برد یا ولت tasks/<شناسه>/>
پرسش‌های باز: <چه چیزی و از چه کسی>
تسک‌های بعدی که باید شروع شوند یا تغییر کنند: <شناسه + دلیل>
موعد جدید (اگر لازم): <تاریخ جلالی>
درس‌ها و روش: <حداکثر ۵ خط: چه جواب داد، چه اصلاحی کاربر خواست، قاعدهٔ تازه برای دفعه‌های بعد>
```
قواعد: بدون مبلغ؛ بدون نقل محتوای حساس ولت؛ فایل حساس روی برد نرود (مستقیم در ولت). اگر فایلی روی برد ضمیمه شد، کتابدار خودش در اجرای بعد آن را به ولت می‌برد.

ایجنت «درس‌ها و روش» را وارد `agent/knowledge/14-learnings.md` و ماژول مربوط می‌کند (ماژول ۲۲)، پس دستیار از فردا با همان دانش کار می‌کند.
