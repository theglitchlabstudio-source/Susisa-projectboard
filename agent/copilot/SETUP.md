# راه‌اندازی دستیار تسک (یک‌بار، حدود ۱۰ دقیقه)
1. در Claude یک پروژهٔ تازه بساز: «سوسیسا — دستیار تسک». پلن تیمی است: Share کن تا امیرحسین هم همان را ببیند.
2. متن `INSTRUCTIONS.md` را در Instructions پروژه بگذار.
3. فایل‌های دانش پایه را به پروژه اضافه کن (فهرست در انتهای INSTRUCTIONS.md).
4. اتصال GitHub (Connectors) را برای حساب فعال کن تا دستیار ولت `susisa-vault` را بخواند. اگر نشد، بسته را پیست کن.
5. هر تسک: چت تازه در همین پروژه، با قالب `START.md`. دو نفر هم‌زمان روی دو تسک = دو چت جدا، بدون تداخل (هر تسک یک مالک و پوشهٔ مجزا در ولت).
6. بسته‌ها را ایجنت مدیر پروژه هر اجرا تازه می‌کند؛ هر لحظه هم می‌شود: `python3 tools/brief.py <شناسه>` (ذخیره در ولت) یا `--open --owner M`.
