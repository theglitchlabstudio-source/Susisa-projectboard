# قالب شروع چت تسک
بگذار در پیام اول هر چت (یا فقط «تسک <شناسه>» اگر اتصال GitHub فعال است):

```
تسک <شناسه> (مثلاً s2m)
من <ممضی/امیرحسین> هستم. بسته را از ولت بخوان، بریف بده، روش کار پیشنهاد کن.
```
اگر اتصال نیست، خروجی `python3 tools/brief.py <شناسه> --stdout` یا فایل `_agent/briefs/<شناسه>.md` را زیر همین پیام پیست کن.
