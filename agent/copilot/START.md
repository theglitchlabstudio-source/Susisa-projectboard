# قالب شروع چت تسک
پیام اول هر چت (دستیار خودش بریف را از برد می‌خواند):

```
تسک <عنوان یا شناسه> (مثلاً «نام آیتم‌های منو»)
من <ممضی/امیرحسین> هستم. بریف را از برد بخوان، بریف بده، روش کار پیشنهاد کن.
```
اگر دستیار نتوانست از اینترنت بخواند: در برد، تسک را باز کن ← بخش «بریف دستیار تسک» ← «کپی بریف» ← در همان چت پیست کن.

برای کل پروژه هم کافی است بنویسی: «وضع پروژه چطوره؟» یا «امروز من چی کار کنم؟». دستیار خودش از گیت‌هاب می‌خواند؛ لپ‌تاپ کسی لازم نیست.
