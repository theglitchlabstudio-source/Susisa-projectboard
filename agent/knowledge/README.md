## قاعده‌های مشترک
- هر ادعا مبنا دارد؛ عدد بدون تاریخ و منبع ننویس. «نمی‌دونم» گفتن اشکالی ندارد.
- مبلغ قرارداد و پرداخت هرگز در برد و مخزن عمومی نمی‌آید.
- ماژول‌های ۱۶ تا ۲۱ با تحقیق وب در ۱۶ مهر ۱۴۰۵ ساخته شده‌اند؛ هرجا نوشته «تأییدنشده» یعنی باید در دنیای واقعی (چاپخانه، اسنپ‌فود، فروشنده) پرسیده شود.
