# برگهٔ بازخورد سافت‌اوپنینگ سوسیسا

> برای پیشخوان، از امشب دوشنبه ۲۰ مهر تا ۲۹ مهر · یه نسخه چاپ کنید و کنار صندوق بذارید

## سه سؤال از مشتری (بعد از حساب، نه وسط غذا)
فقط از ۳ تا ۵ نفر در شب بپرسید. جواب رو **کلمه‌به‌کلمه** بنویسید، خلاصه‌اش نکنید.

1. **از چیزی که انتظار داشتی بهتر بود یا نه؟** (آره / نه)
2. **چرا؟** (همون حرف خودش)
3. **اگه بخوای سوسیسا رو به یه دوستت معرفی کنی، چی می‌گی؟**

چرا این سه تا: یه سؤال آره/نه و یه «چرا» خیلی بیشتر از امتیاز ستاره‌ای به درد می‌خوره. سؤال سوم تست جایگاه برنده: اگه بیشتر مشتری‌ها چیزی مثل «فقط هات‌داگ داره» یا «هات‌داگش فرق داره» گفتن، جایگاه «هات‌داگ تخصصی مشهد» تأیید می‌شه. اگه «کمه» گفتن، باید وزن رو روی منو بنویسیم.

اگه کسی ناراضی بود: **همون موقع** باهاش حرف بزنید و جبران کنید. بیشتر نظرهای بد آنلاین تو ۲۴ ساعت اول بعد از غذا نوشته می‌شن.

## سه خط آخر شب (برای تسک «دفتر سافت‌اوپنینگ» روی برد)
| | امشب |
|---|---|
| ۱. مشتری چی پرسید یا گله کرد؟ | |
| ۲. کدوم آیتم کند بود یا تموم شد؟ | |
| ۳. بیرون‌بر و بسته‌بندی چی شد؟ (خیس شد، سرد شد، ریخت؟) | |
| جواب‌های سؤال ۳ (معرفی به دوست) | |

همین جدول رو عکس بگیرید یا تایپ کنید و زیر تسک «دفتر سافت‌اوپنینگ» بذارید. Claude هر صبح جمعش می‌کنه و می‌رسونه به چک‌لیست افتتاحیه.

## یادتون باشه
- منو تا دو ماه عوض نمی‌شه؛ این بازخوردها برای اجرا، سرعت و بسته‌بندیه.
- عکس واقعی از هر آیتم هم یادتون نره (برای پیج لازمه).
